# Overview

This project is a modern, responsive personal portfolio website developed using **HTML5**, **CSS3**, and **Vanilla JavaScript**. It serves as a professional platform to showcase my technical skills, featured projects, education, and experience while demonstrating front-end development best practices.

The website combines responsive layouts, interactive animations, and dynamic user interface elements to deliver an engaging browsing experience across desktop, tablet, and mobile devices.
